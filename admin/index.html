Website beheer

Log in met een GitHub-sleutel (token) die schrijfrechten heeft op de website-repository.

Hoe maak ik een sleutel?
  1. Open github.com/settings/personal-access-tokens/new.
  2. Naam: Vervat admin. Vervaldatum: bijvoorbeeld 1 jaar.
  3. Repository access: Only select repositories → vervat-website.
  4. Permissions → Repository: Contents: Read and write (en optioneel Actions: Read-only om de publicatiestatus te zien).
  5. Klik Generate token en plak de sleutel hieronder.

De sleutel wordt alleen in deze browser bewaard. Log uit op gedeelde computers.
